# Prompts para construir tu web con Claude

Copia uno, pégalo en [claude.ai](https://claude.ai) y rellena los `[corchetes]` con tus datos.
Empieza por el Prompt 1. Los demás son para mejorar.

---

## Prompt 1 · Crear tu web (empieza aquí)

```
Eres un diseñador web experto. Hazme una página web personal de UNA sola página,
en un solo archivo HTML con el CSS dentro de una etiqueta <style> (sin archivos
aparte, sin frameworks). Que sea moderna, elegante y rápida, fondo oscuro.

Sobre mí:
- Nombre o marca: [tu nombre]
- A qué me dedico: [una frase, ej. "fotógrafo de bodas en Madrid"]
- A quién ayudo: [tu cliente ideal]
- Mi color principal: [ej. naranja / azul / verde]

Secciones que quiero, en este orden:
1. Una barra de navegación arriba.
2. Un hero con un titular potente, una frase y un botón "Hablemos".
3. "Sobre mí" con un par de frases.
4. "Qué hago" con 3 tarjetas de servicios.
5. Contacto con mi email: [tu@email.com]
6. Un footer con el año.

Dámelo como un artifact que pueda ver y descargar. El texto, en español.
```

---

## Prompt 2 · Cambiar el aspecto

```
Me gusta. Ahora cámbiale esto:
- [ej. ponlo más minimalista, con más espacio en blanco]
- [ej. usa una tipografía más redondeada]
- [ej. cambia el color principal a un verde oliva]
Mantén todo lo demás igual y dame el código completo otra vez.
```

---

## Prompt 3 · Añadir una sección

```
Añade una sección nueva de "[testimonios / proyectos / preguntas frecuentes]"
justo [antes del contacto]. Que tenga [3 elementos]. Inventa el contenido de
ejemplo y lo cambio yo luego. Dame el código completo.
```

---

## Prompt 4 · Que se vea bien en el móvil

```
Revisa que la web se vea perfecta en el móvil: que no se salga nada, que los
textos sean legibles y los botones grandes. Si hace falta, ajústalo. Dame el
código completo.
```

---

## Prompt 5 · El código final para publicar

```
Dame el código HTML completo y final en un solo bloque, listo para copiar y
pegar. Sin explicaciones, solo el código.
```

Ese bloque es el que pegas en `index.html` (ver el Paso 4 del README).

---

## Truco

Habla con Claude como hablarías con un diseñador: *"esto no me convence"*, *"más
serio"*, *"que parezca caro"*. No tienes que saber términos técnicos. **Tú diriges,
la IA ejecuta.**
